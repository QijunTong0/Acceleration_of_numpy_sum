# NumPyの合計処理の高速化

このリポジトリは、特にドロップアウトマスクを適用する場合など、配列要素の合計を計算するためのさまざまなNumPy関数のパフォーマンスを比較します。

## 🤔 このリポジトリは何のため？

巨大なNumPy配列を扱う際、パフォーマンスは非常に重要です。特に、計算前に一部の要素を選択的に無視（「ドロップアウト」マスク）する必要がある場合には、その重要性が増します。

このリポジトリでは、2D配列（行列）に対してマスク付きの合計処理を行ういくつかの方法をベンチマークし、さまざまなシナリオで最速のメソッドを見つけます。

## ベンチマーク

行列`A`の合計処理のパフォーマンスを、さまざまな条件下で比較します。

### 関数

以下のNumPyアプローチを比較します。

- `(A * dropout).sum(axis=1)`: マスクで要素ごとに乗算してから合計します。
- `A[:, dropout].sum(axis=1)`: マスクで配列をインデックスしてから合計します。
- `np.dot(A, dropout_vector)`: 合計にドット積を使用します。
- `np.einsum("ij,ij->i", A, dropout)`: アインシュタinの縮約記法を使用します。
- `np.bitwise_count`: bool配列の場合、ハードウェア命令を活用して`True`の値をカウントします。

### データ型

以下のデータ型を持つ行列で関数をテストします。

- `np.int32`
- `np.float32`
- `np.bool_`

### ドロップアウトのパターン

2種類のドロップアウトマスクを使用します。

1.  **列ドロップアウト**: 列全体を保持するかドロップします。これは1Dのbool配列でシミュレートされます。
2.  **ランダムドロップアウト**: 行列の各要素がランダムにドロップされます。これは行列と同じ形状の2Dのbool配列でシミュレートされます。

## 🚀 ベンチマークの実行方法

1.  **リポジトリをクローンします:**
    ```bash
    git clone https://github.com/your-username/Acceleration_of_numpy_sum.git
    cd Acceleration_of_numpy_sum
    ```

2.  **依存関係をインストールします:**

    このプロジェクトでは、パッケージ管理に`uv`を使用します。インストールされていることを確認してください（`pip install uv`）。

    ```bash
    uv pip install -r requirements.txt
    ```
    *注意: `requirements.txt`がない場合は、`pyproject.toml`にリストされている依存関係を手動でインストールできます:*
    ```bash
    uv pip install "numpy>=2.3.5" "pytest>=9.0.1" "pytest-benchmark>=5.2.3"
    ```

3.  **ベンチマークを実行します:**

    ベンチマークは`pytest`を使用して実行されます。以下のコマンドは、すべてのテストとベンチマークを実行します。

    ```bash
    pytest --benchmark-sort=mean
    ```

## 📊 結果

出力には、データ型（`FLOAT32`、`INT32`、`BOOL`）とドロップアウトタイプ（`Random Dropout`）でグループ化されたベンチマーク結果のテーブルが表示されます。

テーブルには、`min`、`max`、`mean`、`stddev`、`rounds`などの統計が含まれています。`mean`列は、各関数の平均実行時間を示す良い指標です。`mean`の時間を比較することで、各ユースケースでどのNumPy関数が最もパフォーマンスが高いかを確認できます。

たとえば、bool配列の場合、`np_bitcount`が標準の`np.sum`よりも大幅に高速であることがわかるかもしれません。列ドロップアウトのあるfloat配列の場合、`np.dot`が勝者かもしれません。
